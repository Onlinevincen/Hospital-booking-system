How to Access the Chatbot

  1. Go to Login Page
  2. Use one of the patient accounts above (you'll need to reset the password first)
  3. After login, you'll be redirected to the patient dashboard
  4. Look for the blue circular chat button in the bottom-right corner

Password Reset Instructions

Since the PHP MySQL driver seems to be unavailable, you have a few options:

  • Option 1: Use phpMyAdmin if available to reset passwords
  • Option 2: Create a new patient account via registration
  • Option 3: Install the PHP MySQL driver

Quick Test - Create New Account

The easiest way to test the chatbot is to create a new patient account:

  1. Go to Registration Page
  2. Fill in the registration form
  3. After registration, login with your new credentials
  4. You'll see the chatbot button on the dashboard
